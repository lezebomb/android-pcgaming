# Dimensity Gaming development

Work in this source tree. The target is a Dimensity 8300 / Mali-G615 / 8 GB
tablet. Real rendered, controllable, stable gameplay is the acceptance goal;
startup, feature probes and synthetic input alone do not establish it.

Prioritize implementation. Run only the few checks needed for a change; avoid
repeating already-passed graphics or controller suites.

The user authorizes keeping this project synchronized with
https://github.com/lezebomb/android-pcgaming. After each meaningful, buildable
code update, commit and push promptly. Inspect the remote first, preserve its
history, and never force-push. Do not upload games, APKs, runtime archives,
private credentials, signing keys, account tools, personal handoff notes,
device captures or tool caches. Keep dependency provenance and licenses.

Use only the authorized app installation/debug scope. No root, system-driver
replacement or other-app data modification. Keep SuperDisplay disabled.
Never record device unlock secrets. Do not bypass DRM or anti-cheat.

Internal continuity notes live in ignored docs/resume-*.md. Consult their
latest append before repeating completed work. Public technical status must
distinguish code changes, build checks and real-device results.
