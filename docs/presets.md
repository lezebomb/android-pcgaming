# 8GB Mali 预设

| 项目 | 低内存优先 | 均衡（默认） | 性能优先 |
| --- | --- | --- | --- |
| 分辨率 | 960×600 | 1280×800 | 1280×800 |
| DXVK 帧率上限 | 30 | 30 | 60 |
| DXVK | 1.10.3 | 1.10.3 | 1.10.3 |
| Vulkan | 系统驱动 + 上游 Wrapper | 同左 | 同左 |
| Present 请求 | FIFO | FIFO | FIFO |
| ASTC/ETC2 转码 | 关闭 | 关闭 | 关闭 |
| BCn | 上游自动 / CPU 路径 | 同左 | 同左 |
| Shader / BCn 磁盘缓存 | 保留 | 保留 | 保留 |
| Box64/FEX | 上游 STABILITY | 同左 | 同左 |
| 跳过图形屏障 / 异步补丁 | 不启用 | 不启用 | 不启用 |
| 人为内存压力 | 移除 | 移除 | 移除 |

参数与读取位置：`DeviceProfiles.java`、`Container.java`、`DXVKConfigDialog.setEnvVars`、`extractGraphicsDriverFiles`。帧率键已对照 [DXVK v1.10.3 配置](https://github.com/doitsujin/dxvk/blob/v1.10.3/dxvk.conf)；旧的默认 1.7.2 未提供这些配置，故改选已捆绑的 1.10.3。

性能预设保留相同转译正确性，仅提高应用级帧率上限；不假设关闭 TSO/x87 一定正确。是否使用更激进 JIT、多块编译或 GPU 纹理转码，需要特定游戏短测试后再保存，不能作为万能默认。

游戏内部纹理、阴影与后处理需要手动选低档；本应用不伪装能统一修改所有游戏配置。其他分辨率 1280×720、1600×1000 可在容器/快捷方式设置中选择。对内存紧张的游戏，960×600 与低纹理是保守起点，仍不保证能运行。

主页按容器应用预设。一款游戏一个容器可实现独立配置；快捷方式自己的覆盖项优先于容器设置。恢复均衡不删除 Prefix 或存档，也不会清除已有磁盘缓存。
