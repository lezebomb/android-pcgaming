# 已知问题与后续开发

1. **当前已通过目标平板基础短测，仍不是完整游戏验收的最终版本。** 联想 TB375FC / Android 16 / 4 KiB 页已成功安装并启动 Wine 配置程序；Freedoom和C-Dogs已通过关卡与基本操控短测；其他Android/ZUI版本、16KiB内存页及大型游戏仍待验证。
2. Wine/Box64/FEX/图形等使用上游预编译包。前端与 JNI 可重新构建，全部二进制从对应源码重建、完整许可证材料尚未完成。
3. 原生探测不创建 surface，swapchain、present mode、AHB 用法级兼容性标为 unavailable。未按 GPU 型号编造结果。
4. 暂未实现 DXVK/Vortek/VirGL 的实机自动选优与失败自动回退；当前推荐路径为系统驱动 + Mali Wrapper + DXVK，WineD3D/其他选项保留上游配置入口但不承诺适用。
5. 5 秒采样不是连续内存峰值；RSS 共享页会重复计数；进程权限可能导致缺失。退出记录不能证明无 GPU 泄漏。
6. 沿用的 HUD 主要用于观察，尚未接入经校准的游戏 P95/P99、1% Low 与触控延迟统计，不输出伪造数据。
7. 主页使用 SAF 导入与导出；旧文件管理器直接访问任意共享目录、旧快捷方式公开路径导出等能力可能不可用。优先使用新主页入口。
8. 预设按容器生效，已有快捷方式覆盖设置需单独恢复。游戏内画质须手动设置。
9. 导入大游戏会复制文件，增加存储占用；失败的部分副本留在本应用 C:/Games。卸载此开发包会删除它自己的游戏副本、配置和存档，正常卸载前应自行导出需要的数据。
10. 0.1.3-dev 已在目标平板修复并复查自编 DX9/11 探针的白屏与红蓝通道互换：实际色块颜色正确，正常退出。该结论限于基础显示场景，该基础探针结论不等于复杂着色器或大型游戏兼容性。详见 `device-graphics-2026-10-21.md`。
11. GPU-only DRI3 缓冲不再强制 CPU 映射；此类 pixmap 的 X11 CPU 读写请求返回 BadMatch，不提供 GPU 读回。普通 GDI 窗口仍使用原 CPU 数据；需留意依赖 XGetImage 读取 DRI3 pixmap 的软件兼容性。GPU 拷贝目前用 glFinish 确保复用前完成，性能需实机观察，不能宣称性能提升。

12. 0.1.7补充Present QueryCapabilities(minor4)，返回保守COPY能力0。0.1.6修复Sync持锁忙等和退出唤醒，但单epoll派发的跨客户端等待仍需异步设计；Warzone未观察到AwaitFence，不能把该修复当作黑屏根因。高级Present兼容性仍待完善。

13. 大体量/3A游戏尚未验收。Mali层+VKD3D2.14.1已通过FL12_0设备、SM6实际绘制、BC1/3/5/7单块采样和稀疏预算限额/释放恢复，不能当复杂游戏或性能结论。Warzone修复弹窗覆盖后已进入第一关3D场景，操控和稳定性仍待完成，偶发资源读失败仍存在。艾尔登法环55.1GB已导入校验，SteamAPI_Init返回0、未进入DX12；本地直启设置不会自动补齐游戏自身接口依赖。
14. 0.1.4导入进度、取消、逐文件空间检查和大小校验已通过一次50.4MB目录导入。取消、空间不足与超过4GB文件尚未实机验证；不支持断点续传。0.1.5自动功能等级已安装验证，0.1.8增加默认关闭的实验Mali层配置。
15. 0.1.11直启/自动启动必要短测通过：含空格完整目标、独立工作目录、带引号参数均实际正确，退出没有重复自动拉起。自动启动默认关闭，3秒可取消，不是设备开机后台自启。ZUI应用列表提示曾再次出现，移除剩余版本查询后未单独重复整轮测试，不宣称所有提示已消失。

16. 0.1.18已有前台库页面接收新外部入口的实际参数/工作目录通过证据。调试更新同名EXE后热续启仍偶有无新日志，冷启可运行，根因待定位，Wine exit0不算游戏成功。
17. 手柄组合写入与失焦归零/返回新输入已通过必要短查，早前恢复失败定位为系统Settings ANR抢焦点。0.1.23–24新增通用键鼠映射、按游戏保存、设备描述符重连匹配及延迟触屏点击取消；真实游戏的完整手柄游玩仍未验收。
18. Superposition曾通过显卡标识覆盖显示免费GUI并进入引擎启动画面；wrapper shader字节/字数越界已定位修复并做单样本回归。最近原库与修复库的GUI均黑屏，没有3D场景/FPS通过证据。见superposition-compatibility-2026-10-22.md。
19. 0.1.28加入每游戏显式选择的Vortek实验后端：固定配套Bionic客户端/Android服务端、GPU专用AHB及完成后拷贝、私有ICD与socket。当前仅离线构建/v2验签通过，未安装实机；采用单缓冲、QueueWaitIdle与glFinish保守同步，不能声称性能改善。Vortek与现有Mali实验层分开选择，不能继承后者BC7/SM6通过结论。
